# Changelog

## 1.0.0

First release.

- Full Tailwind color palette as primitives, plus black and white transparency steps
- 100 semantic color tokens with light and dark modes, including hover, pressed and overlay states
- 11 font families, with Inter as the default
- 95 text styles with desktop and mobile sizes, in five weights per size
- Spacing on a 4px grid and corner radius tokens
- 5 shadow styles that adapt to dark mode
- Generated documentation pages in Figma
- Tokens exported as DTCG JSON and CSS variables
